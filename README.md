# Документация проекта Calculator v2.0.0

## Описание

Это документация для проекта калькулятора, сгенерированная с помощью Doxygen. Документация содержит подробное описание всех функций, классов и тестов проекта.

## Структура документации

- **index.html** - главная страница документации
- **classes.html** - список всех классов и структур
- **functions.html** - список всех функций
- **files.html** - список всех файлов проекта
- **namespaces.html** - список пространств имён

## Просмотр документации

Для просмотра документации откройте файл `html/index.html` в любом веб-браузере.

## Обновление документации

Для обновления документации после изменений в коде выполните команду:

```bash
doxygen Doxyfile
```

## Содержание

Документация включает:

- **Исходный код** (`src/`) - основные функции калькулятора
- **Тесты** (`tests/`) - unit, интеграционные и edge-case тесты
- **API документация** - описание всех публичных функций
- **Примеры использования** - примеры вызовов функций

## Версия

Документация соответствует версии проекта: **2.0.0**

## Язык

Документация сгенерирована на русском языке для удобства разработчиков.
